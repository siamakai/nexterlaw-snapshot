# Jurisdiction notes template

Copy into `content/jurisdictions/index.ts` as one string per country. Keep it factual and sourced; the AI draft may only use what is written here, and a person reviews every draft before it is sent.

```
Country: <name>
Checked by: <name>, <date>

Professional regulator(s) and bar bodies:
- <body> — <what it says about AI, with link>

Data protection and confidentiality:
- <law> — <relevant points for law firms using AI, with link>

AI-specific rules or guidance:
- <rule/guidance> — <status, dates, link>

Professional indemnity / insurance points:
- <point, link>

Notes for the report:
- <anything the reviewer wants every report for this country to mention>
```
